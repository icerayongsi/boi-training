เชื่อมต่อ Database

ระบบเชื่อมต่อฐานข้อมูลผ่าน Cloudflare Access TCP

ดาวน์โหลดสคริปต์เชื่อมต่อ
เลือกระบบปฏิบัติการของคุณเพื่อรันคำสั่งหรือดาวน์โหลดสคริปต์
วิธีที่ 1: รันคำสั่ง One-liner ผ่าน PowerShell (แนะนำ) 
irm .../windows | iex
วิธีที่ 2: ดาวน์โหลดไฟล์สคริปต์ไปรันเอง
ดาวน์โหลด windows-connect-db.ps1
หากติดสิทธิ์ ExecutionPolicy บน Windows ให้เปิด PowerShell แล้วรัน Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass ก่อนรันสคริปต์
วิธีที่ 1: รันคำสั่ง One-liner ผ่าน Terminal (แนะนำ) 
curl -sSL .../unix | bash
วิธีที่ 2: ดาวน์โหลดไฟล์สคริปต์ไปรันเอง
ดาวน์โหลด unix-connect-db.sh
รองรับ Linux (amd64 / arm64 / armv7l), macOS (Apple Silicon M-series & Intel) และ WSL บน Windows สคริปต์จะตรวจจับและติดตั้ง cloudflared ให้อัตโนมัติ
