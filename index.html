ระบบเชื่อมต่อฐานข้อมูล MySQL ผ่าน Cloudflare Access TCP ปลอดภัย ไม่ต้องเปิด Public Port เพียงรันสคริปต์ 1 ครั้งก็เชื่อมต่อได้ทันที

เลือกระบบปฏิบัติการและดาวน์โหลดสคริปต์
⚡ วิธีที่ 1: รันคำสั่งทันที (One-liner ใน PowerShell) แนะนำ 
irm .../windows | iex
📦 วิธีที่ 2: ดาวน์โหลดไฟล์สคริปต์ไปรันเอง
ดาวน์โหลด windows-connect-db.ps1
ข้อควรรู้สำหรับ Windows: หากติดสิทธิ์ Execution Policy ให้เปิด PowerShell แล้วรันคำสั่ง Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass ก่อนรันสคริปต์
⚡ วิธีที่ 1: รันคำสั่งทันที (One-liner ใน Terminal) แนะนำ 
curl -sSL .../unix | bash
📦 วิธีที่ 2: ดาวน์โหลดไฟล์สคริปต์ไปรันเอง
ดาวน์โหลด unix-connect-db.sh
รองรับทุกแพลตฟอร์ม: Linux x86_64, Linux ARM64, macOS Apple Silicon (M1/M2/M3), macOS Intel และ WSL บน Windows สคริปต์จะตรวจสอบสถาปัตยกรรมและติดตั้ง cloudflared ให้อัตโนมัติ
ขั้นตอนการทำงานของสคริปต์
  1. เปิด Terminal หรือ PowerShell แล้วรันคำสั่ง
    สคริปต์จะตรวจสอบและดาวน์โหลด cloudflared binary ของแท้จาก Cloudflare GitHub ให้เองโดยอัตโนมัติ (เก็บไว้ในโฟลเดอร์ ~/.mysql-training/bin)
  2. เลือก Local Port (ค่าเริ่มต้น: 3306)
    หากคุณมี MySQL รันอยู่ในเครื่องอยู่แล้ว สคริปต์จะตรวจจับพอร์ตที่ชนให้อัตโนมัติและขยับเป็น 3307 หรือ 3308 ทันที
  3. เปิด Terminal ทิ้งไว้เพื่อรักษาการเชื่อมต่อ
    เมื่อขึ้นข้อความ Starting Cloudflare Access... แปลว่า Tunnel พร้อมใช้งานแล้ว ห้ามปิดหน้าต่างนี้ หากต้องการหยุดให้กด Ctrl + C
  4. เชื่อมต่อโปรแกรม DB Client / Node-RED
    ใช้ข้อมูล Host เป็น 127.0.0.1 และ Port ที่แสดงบนหน้าจอ เพื่อเข้าสู่ฐานข้อมูลได้ทันที
